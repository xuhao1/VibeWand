# 命令模式

[English](command-mode.en.md) · [Computer use](computer-use.md) · [文档目录](README.md)

按住命令键说一句话，松开后 VibeWand 替你找到应用、会话或控件。它负责找到、打开、按下、把字放好；真正的工作仍由你选的软件完成。

**本页描述当前源码，尚未随 0.8.4 安装包发布；需要 macOS 26。**

## 开启

「设置 → 命令模式」：

1. 打开开关。打开前会列出哪些内容将发给模型服务，见[发出去的内容](#发出去的内容)。
2. 保存一个 DeepSeek API Key。它存在这台 Mac 的钥匙串里，只在启动命令内核时交给它，费用由你的 DeepSeek 账户承担。
3. 模型名留空使用默认（`deepseek-v4-flash`）。

命令的语音走内置识别：系统听写，或「语音输入」里配置的语音 API。它与你听写用不用外置输入法无关，并且按原词转写，不做自动整理。

## 命令键

按住说话，松开执行。

| 输入方式 | 默认 |
| --- | --- |
| VibeKey | 长按旋钮并保持，说完松开。开启命令模式后，模型入口改为长按 OK |
| 手柄 | 按住 L2 |
| 键盘 | 单独按住右 ⌥ 约 0.2 秒；可在设置里换成其他右侧修饰键或关闭 |
| 遥控器 | 没有默认键，请自行绑定 |

「设备与按键」里可以把“命令（按住说话）”绑到任意按键，你自己绑过的键位优先于以上默认。绑在不能按住的按键上时，按一下开始，再按一下结束。关闭命令模式后，这些默认键位随之消失，VibeKey 的长按旋钮回到模型入口。

右 ⌥ 和其他键一起按时照常是修饰键，不会被当作命令。

## 能说什么

- **找会话。**“切到 Codex 里讨论麦克风的那个会话。”Codex 走它自己的会话列表，直接打开；有几个都像时，浮层列出候选。
- **其他应用里找会话。**Claude、DeepSeek Harness、WorkBuddy、飞书、微信没有可查询的列表：VibeWand 把应用带到前台，打开它自带的搜索并填入关键词，之后照常用旋钮选。
- **切应用，打开文件或网址。**“打开备忘录。”
- **操作前台窗口。**“打开 Runtime.swift 那个标签页。”VibeWand 读取这个窗口的控件，按下其中一个、发一个快捷键、选一个菜单项，或把文字放进输入框。
- **纠正。**再按命令键说“不是这个，下一个”。五分钟内的命令属于同一段对话。

再说一句新的命令，会立即中断上一句。

## 进行中

悬浮面板的语音条显示听到的话、正在做的步骤和需要你回答的问题。面板被你隐藏时，命令期间它会自己出现，结束后再收起。

| 需要时 | 设备 | 键盘 |
| --- | --- | --- |
| 选候选 | 转动、摇杆或 R1 / R2 | ↑ ↓ |
| 确认 | 确认键 | 回车 |
| 停止 | 返回键（VibeKey 的 ESC） | Esc |

键盘上的方向键和回车只在有问题等你回答时交给命令；执行过程中只有 Esc 会被接管。问题 45 秒没有回答视为取消。一条命令最多执行 24 步、120 秒。

## 它不会做的事

- **不发送，不提交。**输入的文字停在输入框里，发不发由你决定。
- **删除、发送这类操作每次都等你确认：**名称含删除、丢弃、不保存、发送、提交、支付等字样的按钮和菜单项，多行输入框里的回车，以及 ⌘回车、⌘⌫、⌘Q。
- **只操作一个应用：**按下命令键时在前台的那个，或它为你切到的那个。你切走以后，后续操作作废。
- **不截图，不点坐标。**读不到控件的界面（画布、自绘内容）做不了。
- **不读输入框和文档的内容，**只知道输入框是否为空；不向密码框输入。
- **没有命令行和文件读写。**模型能调用的只有 13 个工具，见[开发指南](development.md)。

## 发出去的内容

开启后，以下内容会发给你配置的模型服务：

- 你说出的命令原话；
- 应用名、窗口标题、会话标题、项目文件夹名，以及正在运行的应用的名字；
- 操作界面时，前台窗口里控件上的文字（按钮名、标签页标题、菜单项）。

不会发给它的：输入框和文档的内容、选中的文字、剪贴板、截图。录音按「语音输入」里的设置处理，不经过模型服务。

关闭命令模式时，VibeWand 的行为与以前一样，不读取这些内容。

**本机记录。**每条命令的原话和执行步骤保存在 `~/Library/Application Support/VibeWand/tasks/`，不含从窗口读到的内容，14 天后自动删除。内核自己的对话日志在同一目录的 `kernel/` 下，只保留最近一次启动的。「设置 → 命令模式 → 清除全部记录」会删除两者。

**内核。**命令模式内置了 DeepSeek Harness 作为内核，只保留模型、会话和 VibeWand 提供的工具：没有它自带的命令行、文件、网页、技能和子代理工具，也去掉了向模型请求附带会话日志和插件清单的两个组件。它使用自己的目录，不读写你自己的 DeepSeek Harness。它会在这个目录里生成一个随机的安装标识并随模型请求发送；清除记录后会换一个新的。

## 验证情况

以下经过自动测试和真实模型的运行：内核进程与工具通道、取消、候选选择与停止、命令键位、随包内核的启动。

以下尚未在真实应用里观察过结果，请在使用时留意：

- Codex 的 `codex://threads/…` 链接是否落在指定会话上；
- VS Code 等应用的标签页和控件是否都能被读到；
- 右 ⌥ 的按住检测是否与你的输入法或其他软件冲突；
- 各应用自带搜索的关键词填入。
