# 手势配置与默认操作

[设置与改键](settings.md) · [默认操作](core-experience.md) · [文档目录](README.md)

VibeWand 0.5.5 延续物理事件、手势识别和应用操作分层。所有按钮的单击、双击、长按、按住 / 松开，以及左右旋转、按住旋钮旋转和手柄左右摇杆的八个方向，都可在「设置 → 设备与按键」中配置。无需编辑源码。

## VibeKey 默认配置

| 手势 | 默认动作 |
| --- | --- |
| 旋钮单击 | 打开会话；选择器内确认候选 |
| **旋钮双击** | 打开 macOS **⌘Tab 应用切换** |
| 旋钮长按 | 阅读 / 编辑时打开模型与强度 |
| 左 / 右旋转，草稿为空 | 下 / 上滚屏，看上下文；输入框留有焦点也一样 |
| 左 / 右旋转，草稿有字 | 左 / 右移动光标 |
| 左 / 右旋转，选择器内 | 上 / 下候选；模型与强度可单独改成滚屏 |
| 麦克风按住 / 松开 | 开始 / 结束所选听写服务 |
| OK 单击 | 确认候选或 Enter |
| 最下面 ESC 单击 | 草稿编辑时删除光标前字符或选区；阅读时 Escape，选择器内取消 |
| ESC 长按 | 草稿编辑时连续删除，松开即停；其他场景与单击相同 |
| 其他按钮的双击 / 长按 | 默认不执行，可自行配置 |

应用切换打开后，旋转选应用，**再单击旋钮或 OK 确认**，ESC 取消。这些键在「切换应用」场景有独立配置。该操作在其他程序前台时也可用；会话、草稿、模型操作交给当前前台应用的适配器；浏览器单击切换标签，详细规则见 [核心体验](core-experience.md)。

## 手柄摇杆方向

> 0.10.2 起，摇杆和方向键上推向上滚、下推向下滚，左右只在有草稿时移动光标；方向键和手柄的其他按键另有「按下即触发 · 按住连发」这种触发方式。现行默认见[默认操作](core-experience.md#手柄一个键一件事)，下面一段是 0.5.5 当时的行为。

「摇杆」分组为左右摇杆分别提供上、下、左、右和按下。方向只提供「拨动 / 持续拨住」导航绑定，不提供单击、双击、长按或普通按住动作：超过死区立即触发，保持方向重复，回中释放并停止，不在回中时补发普通单击。默认拨上 / 拨下对应下 / 上滚屏，左 / 右按场景导航；选择器和应用切换器中沿相应方向选前一个 / 后一个。每个方向都可在不同场景独立改配，已保存的旧配置可继承新增默认方向，显式覆盖仍优先。

持续重复来自真实 `axis` HID 绑定；仅编辑布局不会产生硬件事件。设备逻辑范围、方向和中心需实测，见 [HID 轴配置](hid-profiles.md#回中摇杆轴)。

## 单击与双击的时间

默认双击间隔 0.28 秒、长按时间 0.55 秒，可调整。绑定双击的按钮必须等待双击窗口结束后才执行单击，防止同一次双击先打开会话、再打开应用切换。没有双击绑定时，单击在松开时立即执行。按住旋钮旋转会抑制本次单击与长按。

「按住 / 松开」的听写在按下时立即开始，在松开时释放，不等待单双击判断。其他普通动作绑定到「按住」时在按下时执行一次；绑定应用切换时，按下打开，松开确认，取消事件释放并取消。

## 修改和分享

1. 选择「通用默认」或具体场景：阅读 / 空草稿、编辑、会话、模型、强度、切换应用。
2. 每行选择一个动作；「默认」表示继承预设或通用覆盖。选择「不执行」才会明确禁用这项手势。
3. 动作按「系统功能」「应用功能」「VibeWand 内功能」分类；本地功能可打开设置、显示 / 隐藏面板或切换说明。
4. 修改立即保存到当前模板。VibeKey、手柄、遥控器分别保留配置；可以调整双击 / 长按时间，导入 / 导出 JSON，或恢复当前模板默认。

手柄与遥控器的默认布局见 [模板说明](device-templates.md)。手柄默认操作全部可由右手完成。系统支持的手柄通过 USB 或 macOS 蓝牙配对后自动识别，无需 HID 导入；遥控器和高级兼容覆盖仍需实测配置。选中模板不等于设备已连接，实时状态在连接面板显示。

设置只描述已支持的操作，不执行配置文件中的脚本。配置示例见 [默认手势 JSON](../profiles/default-gestures.json)。示例显式列出默认操作；日常导出只保留用户覆盖与时间设置，方便跨版本继承新增默认项。

## 模型菜单和空草稿

菜单识别同时检查焦点路径与附近弹出菜单，适配弹出后焦点仍留在输入框的情况。没有名称的菜单，只能在刚发出的模型打开请求之后、同一个窗口出现一个新的实际菜单时绑定；请求本身不算打开成功。原生菜单的方向键与确认使用标准系统事件路径。

空草稿优先通过输入框字符数元数据判断；缺少该元数据时，只读取已确认输入框的值并立即转成「是否为空」，不记录或导出草稿文字。候选、弹窗与选择器优先于空草稿滚屏；已确认能移动光标的草稿继续支持删除。0.2.1 的删除已由用户实测确认。

## 取消与清理

断线、睡眠、退出、更改配置或切换演示 / 采集模式会清除待判定的单击和按住状态，不补发点击。应用切换的 ⌘ 键在确认、取消和清理时释放；15 秒没有设备操作会自动取消，以免修饰键保持按住。

实际菜单结构、固件和其他型号还需要实机验证。通用 HID 设备配置是另一层，见 [HID 配置](hid-profiles.md)。

## 历史：0.3.1 滚动事件修正

0.3.0 实测中应用切换已成功，但空草稿滚屏和模型导航未响应。0.3.1 将滚轮改为标准系统事件，聊天滚动位置取输入框所在内容列上方；弹出菜单优先取菜单区域。模型候选的方向键与确认统一走系统键盘路径。事件仍只在目标为前台 Codex 且身份有效时发送；本次包含 60 项自动测试，实际行为需要复测。

## 历史：0.3.2 控件焦点与菜单定位

0.3.1 的两项实测仍未响应。0.3.2 在滚轮事件前定位鼠标命中区域，事件后恢复原位置。模型 / 强度菜单优先枚举实际可访问性选项，旋转聚焦并定位候选，确认执行该选项的原生动作；若无法执行原生动作才使用该选项位置点击。强度滑块先取得控件焦点，再执行原生增减动作；必要时点击当前滑块位置再发左右键，避免键盘事件落到原输入框。该适配仍需要实机复测，不能将动作日志当作界面操作成功。

手柄 0.5.5 默认面键为 ○ 确认、□ 退格、× 返回；× 双击切应用、长按会话或标签页，○ 长按模型（0.10.2 起：会话和模型改到 L1，切应用改为按住 L2，R1 / R2 按住说话，× 和 ○ 只剩返回与确认）。触摸板单指滑动直接移动系统光标，短按鼠标左键，按压动作可在系统动作库中改配。详见 [设备模板](device-templates.md) 和 [原生手柄接入](controller-input.md)。默认滚屏方向已反转；自定义「向上 / 向下滚屏」仍保持动作名称的语义。
